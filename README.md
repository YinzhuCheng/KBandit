# KBandit 教学网页

一个用于演示多臂赌博机（K‑Armed Bandit）的交互式静态网页。

功能概览：
- 设定拉杆数量 K 与奖励分布（伯努利 / 高斯）；
- 支持手动、随机、UCB 策略；
- 展示累积奖励与后悔值（Regret）曲线；
- 纯前端实现，可直接部署到 Cloudflare Pages。

目录结构：
- `index.html`：页面结构与静态资源加载；
- `styles.css`：页面样式；
- `app.js`：核心逻辑与交互。

本地运行：
1. 直接用浏览器打开 `index.html` 即可。
2. 或使用任意静态服务器（可选）：
   - Python: `python3 -m http.server 8080`
   - Node: `npx serve .`

使用说明：
1. 在“参数设置”中选择拉杆数量 K 与奖励分布；点击“生成参数表”。
2. 如需快速实验，可点击“随机化参数”，将自动重置统计并刷新曲线。
3. 点击“应用参数”会从表格读取参数并开始新的实验（重置统计）。
4. 策略选择：
   - 手动：在表格每行点击“拉一次”进行采样；顶部的“执行 N 步”按钮将被禁用；
   - 随机：使用等概率随机选择臂；
   - UCB：使用 UCB1（c=1）策略进行选择。
5. 右侧显示总步数、累积/平均奖励、最优臂与最优期望奖励 μ*、总后悔值；下方展示曲线。

算法说明（简要）：
- 伯努利臂奖励 ∈ {0,1}，期望即为 p；
- 高斯臂奖励 ~ N(均值, 标准差)，期望为均值；
- 总后悔值：`Regret(t) = t * μ* - 累积奖励`。

部署到 Cloudflare Pages：
1. 将本项目推送到 GitHub/GitLab。
2. 登录 Cloudflare，进入 Pages 创建新项目，选择你的仓库。
3. 构建设置：
   - 构建命令：留空（本项目为纯静态）或 `echo "skip build"`；
   - 输出目录：`/`（或保留默认根目录）。
4. 部署完成后即可通过 Pages 域名访问。
